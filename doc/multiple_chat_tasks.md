# 多会话桶（Multi-chat / Multi-bucket）任务清单

依据 `doc/multiple_chat.md` 分解，按当前实现基线、隔离契约、cwd 自动分桶、资源生命周期、API 一致性和真实网页验收组织任务。

> 状态：`DONE` / `TODO` / `BLOCKED` / `WONTFIX`。
> 优先级：`P0`（正确性与数据隔离）/ `P1`（功能增强与稳健性）/ `P2`（性能、观测与体验）。
> `DONE` 仅表示代码能力已经确认存在，不代表相关验收测试和真机测试全部完成。未实际执行的测试不得标记为通过；真实网页测试不得用单元测试结果代替。
> 本清单是实施和验收跟踪文件。完成任务时应同步更新状态、测试结果和必要证据。

**实施要点**：
1. 请求已进入 `send_chat()` 但尚未拿到 `_session_lock()` 时，页面不得被回收。

8. `_page_lock` 只保护建页、回收和淘汰的短临界区，不覆盖模型生成过程。
